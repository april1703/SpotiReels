# SpotiReels
This application is a **Spotify Demake** with an added **Reels feature**, built using **React (frontend)** and **Docker (backend)**. SpotiReels replicates core Spotify features such as playlist browsing, track playback, and user authentication. Also introduces a new "Reels" feed for music discovery. 

## Features
* User login with Spotify account
* Browse and listen to playlists 
* Create and edit playlists 
* See and upload music-related reels

---
## Getting Started
### Prerequisities
* Node.js/React
* Docker Desktop
* Spotify Developer Account (for API key)
